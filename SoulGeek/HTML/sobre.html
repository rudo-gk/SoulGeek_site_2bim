Sobre Nosso Site

O SoulGeek é um catálogo de entretenimento desenvolvido como projeto educacional, criado para facilitar a busca de informações sobre filmes, séries e atores. Utilizando dados obtidos por meio da API TVMaze, o site reúne em um único lugar informações atualizadas, permitindo que qualquer usuário explore o catálogo de maneira simples e intuitiva.

Como Funciona

Navegar pelo SoulGeek é muito simples. Basta acessar uma das páginas disponíveis para visualizar o catálogo de filmes, séries ou atores. Também é possível utilizar a barra de pesquisa para encontrar rapidamente um título específico. Ao selecionar um item, o usuário pode visualizar informações detalhadas, como descrição, elenco, imagem e outras informações fornecidas pela API.

Sobre a API

O SoulGeek utiliza a API TVMaze para obter informações atualizadas sobre séries, filmes e atores. Todas as imagens, descrições e demais informações exibidas são carregadas diretamente da API, garantindo um catálogo sempre atualizado sem a necessidade de armazenar esses dados localmente.

Perguntas Já Respondidas

O site é gratuito? Sim. O acesso ao catálogo e às funcionalidades do site é totalmente gratuito. Preciso criar uma conta para utilizar o site? Não. A maior parte das funcionalidades pode ser utilizada sem cadastro. A conta existe para disponibilizar recursos personalizados aos usuários. As informações são atualizadas? Sim. Como os dados vêm diretamente da API TVMaze, as informações acompanham as atualizações realizadas pela plataforma.

Onde Buscar Ajuda

Caso encontre algum erro, tenha dúvidas sobre o funcionamento do site ou queira enviar sugestões de melhorias, entre em contato com a equipe responsável pelo projeto. Como este é um projeto acadêmico, todo feedback é bem-vindo e ajuda no desenvolvimento da plataforma.

Navegando pelo SoulGeek

Para aproveitar melhor o site: Utilize a barra de pesquisa para localizar filmes, séries ou atores; Explore as páginas do catálogo para descobrir novos conteúdos; Faça login para acessar os recursos disponíveis para usuários cadastrados; Utilize o menu lateral para navegar rapidamente entre as principais páginas do sistema.

Nosso Catálogo

O catálogo do SoulGeek reúne informações sobre filmes, séries e atores obtidas diretamente da API TVMaze. Cada página apresenta imagens, descrições e informações relevantes para facilitar a descoberta de novos conteúdos. O objetivo é oferecer uma experiência simples, rápida e organizada para quem procura informações sobre entretenimento.
